5.6.3  Test Cases for the Alert Engine

The test cases below cover the alert engine: the evaluation of a milestone against the live data of the shipment it belongs to, the resolution of the deadline each alert rule is timed against, the decision as to whether a rule should fire at a given moment, the resolution of the recipient and the despatch of the message, and the behaviour of the scheduled run as a whole. The evaluation logic was exercised by an automated test suite executed against prepared shipment data, and the remaining cases were carried out by hand against the running system; where the expected result concerns stored data the database was inspected directly after execution.
